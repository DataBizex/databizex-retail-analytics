# Sample data — SYNTHETIC

Both files are **synthetic**. They were generated by
`scripts/generate_sample_data.py` with a fixed seed (20240101).
Product names are generic. There are no real businesses, customers,
prices or personal data.

| File | Rows | Content |
|---|---|---|
| `retail_sales_clean.csv` | 1,500 | Valid orders, 2024-01-01 to 2025-12-31 |
| `retail_sales_demo.csv` | 1,525 | Same orders with injected issues (below) |

Columns: `order_id, order_date, country, product, category, quantity,
unit_price, discount_pct, unit_cost` (prices and costs in EUR).
Countries: Germany, France, Spain, Italy, Netherlands, Belgium.
25 products in 5 categories: Furniture, Lighting, Kitchen, Textiles, Storage.

## Issues injected into `retail_sales_demo.csv`

Each issue is on a different row, so the counts are exact.

| Issue | Count | Details |
|---|---|---|
| Exact duplicate rows | 25 | Copy placed right after the original row |
| Missing values | 18 | 6 country, 4 product, 4 quantity, 4 discount_pct |
| Invalid dates | 8 | e.g. `2024-13-45`, `31/02/2025`, `not a date` |
| Invalid numeric values | 6 | 2 each in quantity, unit_price, unit_cost (e.g. `two`, `#REF!`) |
| discount_pct outside 0–100 | 5 | 120, 150, -5, 250, 101 |
| Negative values | 6 | 2 each in quantity, unit_price, unit_cost |

After removing duplicates, 1,500 rows remain. 25 of them
(4 + 4 + 6 + 5 + 6) are excluded from KPIs. 8 rows with invalid dates
still count in totals but not in the monthly trend.
